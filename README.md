# Loan EMI Calculator

A Python application that calculates the monthly Equated Monthly Instalment (EMI) based on the loan amount, annual interest rate, and loan tenure.

## Features
- Accepts loan amount, interest rate, and tenure.
- Calculates monthly EMI using the standard EMI formula.
- Handles zero interest rates and invalid inputs.
- Displays the monthly EMI with two decimal places.

## Technologies
- Python

## How to Run
1. Install Python 3.
2. Open the terminal in this folder.
3. Run:

   `python app.py`

## Formula

EMI = P × R × (1 + R)^N / ((1 + R)^N − 1)

Where:
- P = Principal loan amount
- R = Monthly interest rate
- N = Total number of monthly instalments
